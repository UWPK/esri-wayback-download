# Esri Wayback 历史影像工作流技能

按区域和时间需求查询、筛选并交付 Esri World Imagery Wayback 历史底图。这个 agent skill 面向 Codex、Pi 等支持技能的助手，把影像任务拆成可检查的步骤：先选对 Wayback 发布版本，再核实影像实际拍摄日期和区域覆盖，最后下载、拼接、裁剪并检查 GeoTIFF。

它适合需要制作历史底图、整理多期影像、核查某个年份是否覆盖研究区，或把影像下载过程做成可复现记录的 GIS 与遥感工作。技能提供判断规则、跨平台配置和质量检查流程；具体任务由助手根据你的数据、环境与服务响应执行。

## 什么时候选 Wayback

Esri Wayback 是持续更新的 World Imagery 底图历史版本。**版本发布日期不等于其中每一块影像的拍摄日期**：同一版本的不同位置可能来自不同时间。若任务关心某一年拍摄的影像，不能只按版本标题选日期；需要检查影像元数据、统计目标年份覆盖，并把未知日期或跨年份区域单独说明。

常见任务包括：

- 比较一个区域在多个 Wayback 发布版本中的地表变化。
- 为指定拍摄年份筛选候选版本，并估算研究区的日期覆盖率。
- 按行政区、流域或自定义边界下载瓦片，拼接并裁剪为 GeoTIFF。
- 记录瓦片清单、缺失区域、来源版本和检查结果，便于复跑或审阅。

若你更需要按 Google Earth 历史影像索引查询可用日期，可同时查看 [`google-earth-history`](https://github.com/UWPK/google-earth-history)。两种来源应分别记录；需要组合时，每块影像的实际来源也要可追溯。

## 工作流程

1. 明确区域边界、目标时间含义、输出坐标系和分辨率需求；先判断请求的是 Wayback 发布日期还是影像拍摄年份。
2. 查询官方 Wayback 发布目录，记录目录快照、候选版本及其日期；用目标区域的小范围样本确认瓦片服务可用。
3. 若按拍摄年份筛选，查询影像元数据并核对分页、空间范围与地图级别，统计目标年份覆盖，同时单列未知日期和跨年份重叠。
4. 生成固定的瓦片下载计划，按小范围试跑后再扩展。下载时检查响应内容和图像可读性，失败时有限重试；支持在参数一致时恢复未完成任务。
5. 拼接、裁剪并写出有坐标的 RGB GeoTIFF，检查 CRS、仿射变换、分辨率、掩膜、缺块和影像预览。
6. 汇报使用版本、日期定义、瓦片成功/缺失数量、覆盖检查范围和仍需注意的限制。

## 使用方式

在支持 agent skills 的助手中安装本仓库的技能目录，开启新会话后描述任务。建议在请求中写明区域文件或边界、希望使用的时间含义、输出目录、坐标系及是否允许缺块。例如：

> 用 Esri Wayback 检查这个流域在 2018 年拍摄影像的覆盖情况。先比较候选版本，再下载覆盖较好的版本，输出裁剪后的 GeoTIFF 和缺块/日期覆盖报告。不要把 Wayback 发布日期当作拍摄日期。

可先从小范围开始验证服务、投影与输出，再扩大到完整研究区。技能入口为 [`SKILL.md`](SKILL.md)，操作细节见[跨平台配置与示例](references/platforms.md)和[项目工作流参考](references/project-workflow.md)。

## 安装栅格处理环境

完整克隆或下载仓库后，准备 Python 3.10+，在仓库目录运行：

```bash
# macOS / Linux
python3 scripts/setup.py

# Windows（也可使用 python scripts/setup.py）
py -3 scripts/setup.py
```

安装器创建仓库内独立环境、安装 Python 栅格依赖，并实际写入和读取一个小型 GeoTIFF。安装完成后，`local-runtime.json` 记录本机验证过的运行路径。该文件、`.venv` 和其他运行时文件属于本机状态，不要提交到仓库或复制到另一台电脑；在目标电脑重新运行安装器即可。

安装需要 Python、网络和所选目录的写入权限。安装器不会关闭 TLS 验证或修改系统证书；如网络环境要求自定义 CA，可阅读安装脚本参数并显式指定可信证书。`--plan` 可预览安装步骤。完整选项见 `python scripts/setup.py --help`。

> 安装器准备栅格处理环境，不是独立的一键区域下载器。实际查询、下载与拼接由 agent skill 根据任务执行。若只想阅读流程，可直接查看本仓库的 `SKILL.md` 和 `references/`。

## 交付与质量检查

典型交付可以包括：裁剪后的 GeoTIFF、边界外掩膜、下载与缺失瓦片清单、所用 Wayback 版本和时间说明、覆盖率统计、地图预览及运行日志。具体文件以任务范围为准。完整性应通过计划瓦片与下载清单对账、栅格空间信息检查和像元抽样共同判断；单个 HTTP 成功响应或局部抽样不能证明全区完整。

对拍摄日期覆盖的统计应注明分母、目标年份、未知日期及重叠面积的处理方式。不同版本拼接补洞时，必须记录每块影像的来源；不能把多个版本的混合结果描述为单一版本的完整覆盖。

## 影像解释、署名与许可

Wayback 提供的是**渲染后的 RGB 底图瓦片**，不等同于原始传感器影像，也不提供可直接假定的原始波段、辐射定标或统一拍摄日期。它可用于历史底图、可视化和适当限定的变化检查；若研究需要原始多光谱数据、严格辐射分析或明确的传感器产品，应选择相应的原始数据源。

下载和再发布影像前，请核对 Esri、影像供应商及相关服务的最新条款，并保留服务要求的署名与来源说明。数据的可用性、日期覆盖、请求速率和服务行为由上游服务决定，本仓库不保证特定区域或日期一定有数据。请勿发布访问令牌、私有区域数据或本机运行状态文件。

**许可状态：**当前仓库尚未包含 `LICENSE` 文件。发布为开源项目之前，请维护者选择并添加明确的开源许可证；在此之前，不能仅凭公开可见就推断代码和文档可被自由复制、修改或再发布。影像数据、上游服务和第三方依赖始终遵循各自条款，不因本项目未来采用的许可证而获得额外授权。

## 平台与验证

安装工作流已通过 Windows x64、macOS Apple Silicon 和 Intel Mac 的持续集成安装检查。维护环境还完成过小范围在线瓦片下载与 GeoTIFF 读写验证。CI 主要验证依赖安装和栅格读写，不代表所有地区、日期、地图级别或网络环境均可下载。大范围下载、特定拍摄年份覆盖和断点恢复效果应在目标区域先做小范围验收。Linux 可按文档配置 Python 与 GDAL/Rasterio 环境；其具体依赖组合由使用环境决定。
